Project Details

📋 Project Overview

This project was developed as a group project for the PPP (Professional Practice and Portfolio) module at SLIIT City University. ACR Mart is a comprehensive item management system designed for retail businesses to manage products, categories, and inventory operations efficiently.

👨‍💻 My Role: Full Stack Developer & Database Designer — responsible for backend development, database architecture, frontend integration, and ensuring seamless functionality across all modules.

⏳ Status: Not Hosted Yet — Fully developed locally with complete frontend and backend functionality. Hosting pending deployment.

✨ Features

  • Item management (add, update, remove items with images)
  • Category management for product organization
  • Inventory tracking with real-time stock updates
  • Sales reports and analytics dashboard
  • User authentication with role-based access (Admin, Staff)
  • Responsive and clean interface for desktop & tablet
  • Search and filter functionality for products

🛠️ Technologies Used

HTML5 CSS3 JavaScript PHP MySQL Bootstrap 5 AJAX jQuery
