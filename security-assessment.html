Project Details

📋 Project Overview

This project was conducted as part of an academic requirement for the Computer Security module at SLIIT City University. The objective was to analyze the existing IT systems of UTE CAT Pvt Ltd, identify potential security vulnerabilities, and propose mitigation strategies based on best security practices and industry standards.

👨‍💻 My Role: Security Analyst (Academic Project) — responsible for vulnerability identification, risk assessment, documentation, and preparation of structured security assessment reports with actionable recommendations.

🛠️ Tools & Methodologies Used

Nmap Wireshark Vulnerability Assessment Framework Risk Assessment Matrix OWASP Guidelines NIST Standards
scope

Assessment Areas

🌐 Network Security Review

Analysis of network architecture, firewall configurations, open ports, and potential entry points for unauthorized access.

⚙️ System Configuration

Evaluation of system hardening, patch management, default credentials, and configuration vulnerabilities.

🔐 Access Control Review

Assessment of user authentication mechanisms, privilege levels, password policies, and user access management.

📊 Risk Evaluation

Classification of identified vulnerabilities by severity level (High/Medium/Low) with potential impact analysis.

findings

Key Findings

🔍 Identified Vulnerabilities

  • 🔴 High Risk: Outdated firewall firmware with known vulnerabilities
  • 🔴 High Risk: Default administrative credentials on network devices
  • 🟡 Medium Risk: Lack of regular security patch management
  • 🟡 Medium Risk: Weak password policy enforcement
  • 🟢 Low Risk: Unused open ports exposing service banners
  • 🟢 Low Risk: Missing security headers on web interfaces

📝 Recommendations Provided

  • Update and harden firewall configurations with regular firmware updates
  • Implement strong password policies and multi-factor authentication
  • Establish regular patch management and vulnerability scanning schedule
  • Disable unused ports and services to reduce attack surface
  • Conduct regular security awareness training for IT staff
  • Implement network segmentation for critical systems
outcomes

Learnings & Takeaways

📊 Outcomes & Learnings

  • Successfully identified critical security gaps and potential threat vectors
  • Recommended practical, implementable security improvements
  • Improved understanding of real-world security risks in corporate environments
  • Gained hands-on experience in security assessment methodologies and reporting
  • Developed skills in risk classification and mitigation strategy development

🎓 Key Takeaways

This project provided invaluable experience in conducting professional security assessments, understanding enterprise security challenges, and communicating technical findings to stakeholders. It reinforced the importance of proactive security measures and regular vulnerability assessments in maintaining organizational security posture.
